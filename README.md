# Legal AI
Production-style AI Legal Document Explainer.

## Features
- PDF/TXT/DOCX upload
- Text extraction
- Legal document classification
- Clause extraction and risk scoring
- Plain-language simplification
- Extractive summarization
- Translation-ready API
- Document chat with source-context retrieval
- SQLite persistence
- FastAPI backend + React/Vite frontend
- Docker Compose

## Run
```bash
docker compose up --build
```
Open http://localhost:5173 and API docs at http://localhost:8000/docs.
